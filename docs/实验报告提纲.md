## 2. 关键实现与难点
- 异步评测流程（`asyncio.create_task` / `asyncio.create_subprocess_exec`）。

- 资源限制取值顺序：题目配置 → 语言配置 → 系统默认值。
- Session 认证与权限控制（401/403 边界、banned 处理）。
- 日志可见性与访问审计（`view_logs`）。
- 题目删除级联清理、题目修改不触发已通过提交重判。
- AI 命题：OpenAI 兼容接口调用、任务状态机、SSE 进度、中断、Token/费用统计、密钥保护。
